## Requirements

Node.js 20+, pnpm, Git, and a Supabase project.

:::caution[Security note]
Never commit `.env`, service-role keys, JWT secrets, PayOS secrets, or SMTP passwords.
:::

## Install

```bash
git clone https://github.com/withnexora/nexora.git
cd tech-ecommerce-store
pnpm install
```

Set the project URL and publishable/anon key in `client/supabase-config.js`, then run `supabase-unified.sql` against a new or empty database.

```bash
pnpm dev
# open http://localhost:3000
```

## Release checks

```bash
pnpm test
pnpm check
pnpm build
```

Main entrypoints include the storefront, `/admin.html`, `/admin-en.html`, `/orders.html`, and `/affiliate.html`. Grant Admin access using [ADMIN_SETUP.md](https://github.com/withnexora/nexora/blob/main/ADMIN_SETUP.md); never use a default password.
