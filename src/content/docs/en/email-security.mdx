---
title: "Email and security"
description: "SMTP, Resend, password recovery, and production security rules."
---

Use SMTP or the Resend API for transactional email and password recovery. Configure SPF, DKIM, and DMARC for the sender domain; never put passwords in the Admin form or Git.

## Secrets

SMTP passwords, Resend keys, PayOS keys, service-role keys, and JWT secrets belong only in Render/aaPanel/server environment variables. The frontend receives only public Supabase configuration.

## Recovery

Configure local, preview, and production redirect URLs under Supabase Auth. Test reset emails on an HTTPS domain before launch.

See [SMTP_SETUP_BILINGUAL.md](/en/reference/smtp-setup/) and [RENDER_ENV_SETUP_BILINGUAL.md](/en/reference/render-env/).
